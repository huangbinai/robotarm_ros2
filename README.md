# reBotArm ROS 2

ROS 2 Jazzy workspace for the reBotArm B601, including hardware control, MoveIt, teach-and-replay, teleoperation, visual grasping, calibration, MuJoCo simulation, and task-level voice control.

The maintained project guide is available in Chinese: [README_zh.md](README_zh.md).

Documentation index: [docs/README.md](docs/README.md).

The hardware runtime target is VMware/Ubuntu 24.04. The Windows checkout is intended for source maintenance and offline tests, not direct MotorBridge serial operation.
