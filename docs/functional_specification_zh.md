# reBotArm 功能说明书

## 1. 文档目的

本文说明当前仓库已经具备的功能、模块边界、输入输出、正常流程和失败处理。它用于项目交接、功能评审和二次开发，不替代具体设备的安全操作规程。

## 2. 系统范围

系统以 ROS 2 为集成总线。真机通信只由 `rebotarmcontroller` 持有；规划、示教、遥操作、视觉和语音模块通过 ROS 接口提出目标，不能直接访问电机 SDK。

```text
操作员 / 任务输入
  ├─ 网页、键盘、RViz ──> teleop / dashboard
  ├─ 示教文件 ─────────> teach
  ├─ RGB-D / GraspNet ─> vision
  └─ 文本与语音 ───────> voice_control
                            │
                            v
                 motion / MoveIt 安全规划
                            │
                            v
                 rebotarmcontroller
                            │
                            v
              MotorBridge + 电机 SDK + B601
```

MuJoCo 可以替换最后两层作为仿真执行后端。一个 ROS 命名空间内只能存在一个轨迹控制后端，不能同时启动真机控制器和仿真控制器。

## 3. 真机控制

### 3.1 连接与使能

控制器启动后连接总线并读取反馈，但连接成功不代表电机已使能。操作员或上层程序必须先检查 `/rebotarm/arm_status`，再调用 `/rebotarm/enable`。使能过程按当前位置建立保持目标，避免把历史目标直接下发给机械臂。

生命周期状态用于区分连接、使能、保持、运动、失能和断开过程。进入 `DISABLING` 或 `DISCONNECTED` 后，动作收尾不能再次把状态写回已使能保持。

### 3.2 共享总线和反馈

六轴机械臂与夹爪共享通信总线。控制器集中调度命令与反馈，默认硬件反馈刷新频率为 `50 Hz`。每个电机维护反馈序号、接收时间和有效缓存；重复帧、无效帧和超过 `0.15 s` 的旧帧不能冒充新状态。

J2、J3 的反馈接受范围允许到 `+0.02 rad`，用于兼容零点附近的小量正偏差。该值不是规划上限，也不能作为正向运动目标。

### 3.3 运动接口

控制器提供三类上层运动入口：

- `MoveToPose`：输入末端 Pose 和持续时间，执行笛卡尔目标轨迹。
- `FollowJointTrajectory`：接收标准关节轨迹，适配 MoveIt、示教回放和任务规划。
- `MoveToPoseIK`：完成 IK 求解和目标更新，适合预检查或小步位姿控制。

轨迹在执行前检查有限数值、关节范围、起点误差、时间单调性、速度和加速度。执行时按轨迹时间插值，并在结束后检查最终关节误差。取消、抢占、超时、反馈异常或保护性失能都会终止成功判定。

### 3.4 命令仲裁

机械臂和夹爪分别具有互斥命令所有权。默认 `cmd_arbitration=reject`：资源繁忙时拒绝新命令。`preempt` 仅应在调用方明确具备安全停止和状态恢复逻辑时使用。

### 3.5 停止和关闭

`trajectory_stop` 停止当前机械臂运动并尽量保持当前位置；`gripper/stop` 终止夹爪执行。控制器关闭时先尝试平滑退出重力补偿，再执行硬失能并验证新反馈，最后断开通信。失能或断开无法验证时返回失败并记录错误，不再把未知物理状态报告为成功。

## 4. 夹爪控制

夹爪位置命令使用米，允许范围为 `0–0.085 m`。负值、超过 `0.085 m`、NaN 和无穷值直接拒绝。

位置控制包含目标渐变、速度限制、力矩上限和按距离计算的动态超时。显式校零必须等待校零之后的新反馈，不能用旧缓存判断成功。闭合端约 `1 mm` 的容差仅用于接收反馈，不修改零位，也不扩大命令范围。

抓取完成不能只依靠“夹爪已闭到底”。有效接触判断至少需要新反馈、实际闭合行程和堵转/速度条件；未配置独立力传感器时，默认不把力矩单独作为接触证据。

## 5. 重力补偿和模式切换

控制器支持 `POS_VEL ↔ MIT` 的受控切换，速度模式默认关闭。进入重力补偿前检查起始速度和新鲜反馈，再渐变建立 MIT 增益；退出时经过阻尼、速度等待、位置锁定和 POS_VEL 保持阶段。

模式切换期间拒绝冲突动作。详细参数和验证步骤见[模式切换测试](mode_transition_test.md)。

## 6. MoveIt 与运动层

`rebotarm_motion` 负责通用轨迹算法和执行协调，包括：

- Pose 预览与执行服务；
- MoveIt 规划服务适配；
- 轨迹时间参数化、速度/加速度/jerk 约束；
- 碰撞预检、起点对齐和运行时跟踪保护；
- 真实任务失败后的保持、返回起点或受控失能策略；
- 成对轨迹记录与对比协议。

MoveIt 的 URDF、SRDF、规划组、碰撞模型和关节限制只由 `rebotarm_moveit_config` 管理。运动算法不能复制到 Dashboard 或示教节点中。

## 7. 示教录制与回放

### 7.1 录制

`TeachRecorderNode` 订阅关节状态，按反馈批次去重，将样本写入 JSONL 文件。录制可配合重力补偿，但录制节点不直接访问硬件。

### 7.2 准备轨迹

原始示教数据不能直接视为安全执行命令。回放前依次完成读取、有限值检查、去重、滤波、重采样、时间重定时、起点对齐和可选碰撞检查，生成 prepared trajectory。

### 7.3 回放

`TeachReplayNode` 把 prepared trajectory 发送给标准轨迹 Action，并监控跟踪误差和停止服务结果。`dry_run` 只检查和生成轨迹，不驱动机械臂。回放失败时按照控制器健康状态决定保持、返回本轮起点或受控失能。

## 8. 遥操作与网页 Dashboard

`rebotarm_teleop` 将键盘或网页意图转换为上层 ROS 命令，并负责夹爪可视关节状态桥接。`rebotarm_dashboard` 提供网页资源、HTTP 路由、SSE 状态流和服务客户端。

Dashboard 只显示状态和调用接口，不拥有轨迹生成、碰撞检测、示教重定时或 SDK 代码。网页预览和真实执行必须是可区分的操作。

RViz 末端拖动使用 MoveIt MotionPlanning 工作流。旧 `rebotarm_interactive_control` 仅保留兼容导入和旧入口，不应继续添加业务实现。

## 9. 视觉抓取

正式链路为：

```text
Gemini 2 RGB-D
  -> YOLO 检测
  -> GraspNet 6D 候选
  -> 新鲜度、工作空间、姿态、IK 和碰撞筛选
  -> GraspPlan
  -> 预抓取、接近、闭合、抬升、放置或撤退
```

候选和计划都有新鲜度限制。无候选、无效候选或输入断流时必须清除/拒绝旧计划，不能继续执行缓存目标。执行器使用互斥锁避免两个抓取请求同时进入状态机，停止请求会同时终止运动和夹爪步骤。

`execution_mode=plan_only` 只规划和显示；`execute`/`real` 才允许进入执行流程。第一次部署必须先完成相机内参、手眼标定、TCP、坐标系、桌面边界和 MoveIt 可达性检查。

## 10. 标定

`rebotarm_calibration` 集中维护手眼配置加载、刚体变换、TCP 标定和残差分析。视觉模块通过配置读取标定结果，不再各自复制标定算法。标定文件应保存采集日期、设备、坐标系方向、样本数和残差结果。

## 11. MuJoCo、Real2Sim 和 Sim2Real

仿真包提供 MuJoCo 模型、无头 ROS 节点、Viewer、轨迹控制、接触读取、Reach/Pick 环境、批量环境和 Gymnasium 适配。Real2Sim 桥只订阅真机状态并驱动仿真显示，不向真机发命令。

硬件、MoveIt 和 MuJoCo 模型的关节范围及 effort 应同步。当前 J1–J3 effort 为 `27`，J4–J6 为 `7`。仿真通过不代表实机安全，Sim2Real 前仍需检查速度、力矩、碰撞和坐标系差异。

## 12. 文本与语音控制

语音模块将文本、音频或实时事件解析为受约束的任务意图，再由安全守卫检查动作类型、方向、距离、速度比例和执行模式。

- `dry_run`：只解析和输出计划，推荐默认模式。
- `sim`：发送给仿真动作接口。
- `real`：允许调用真机链路，必须在其他安全层已通过后显式启用。

自然语言模型输出属于不可信输入，必须经过结构化 schema 和安全限制，不能直接拼接为底层电机命令。

## 13. 独立主从跟随工具

`star_arm_102_rebot_b601_follow/` 收录 Star Arm 102-LD 到 reBot B601 的 SDK 主从映射工具。它具有独立依赖、配置和入口，不由主 ROS launch 启动。使用前应单独确认端口、关节方向、比例、限位和急停路径。

## 14. 不在当前范围内

- P0 Gate B/C 真机验收工具未迁入。
- Windows 直接运行 MotorBridge 不是当前部署方案。
- 离线单元测试不能证明真机动力学、制动或碰撞安全。
- `rebotarm_interactive_control` 不接受新的功能实现。
